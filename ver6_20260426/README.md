# フタル酸誘導体の活性予測モデル
セルロースの加水分解に対して高活性なフタル酸誘導体を予測するモデルを構築する．

## 必要な環境
- Python 3.11

## インストール
```
pip install -r environment.yml
```

## 使い方
1. データセットの準備
    - `data/` ディレクトリに、フタル酸誘導体の構造データと活性データをCSV形式で配置する．
    - CSVファイルは、以下のような形式である必要がある．
      ```
      substract,cas,smiles,glucose,conversion,selectivity
      フタル酸,88-99-3,O=C(C1=CC=CC=C1C(O)=O)O,13.3,26.6,50
      ...
      ```

2. データの前処理
    - `preprocess.py` により、データを前処理する．

3. 特徴量の取得
    - `features.py` により、分子構造及びDFT計算から特徴量を取得する．

4. モデルの学習
    - `train_all.py` により、全ての特徴量を用いてモデルを学習する．

5. 化合物の予測
    - `predict_all.py` により、学習したモデルを用いて新しい化合物の活性を予測する．
